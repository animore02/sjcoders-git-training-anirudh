# Day 2 - OOP, Collections and Architecture

This is my Day 2 training work:

In this task, I created a small Java console application for managing bookings.

## What I Learned

### OOP

- Class and Object
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

### Java Collections

I used:

- ArrayList to store bookings
- HashSet to store unique service names
- HashMap to find a booking using its booking ID
