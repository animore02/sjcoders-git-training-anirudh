# Git & GitHub Practice

This repository is where I practice the **basic Git and GitHub workflow used in software teams** — 
the everyday commands and processes developers use to track changes, collaborate, and manage code.

## 🎯 Goal
To get hands-on with the core Git/GitHub workflow followed in real software teams:
1. Initialize/clone a repo
2. Make changes and track them
3. Commit changes with meaningful messages
4. Push changes to GitHub
5. Work with branches for new features
6. Merge changes back into the main branch
7. Pull updates from a shared/remote repo

## 📁 Structure
- `README.md` — overview of this repo and its purpose
- `training-notes.md` — notes on Git/GitHub concepts and commands, updated as I learn

## 🛠 What I'm Practicing
- Basic Git commands (`init`, `add`, `commit`, `status`, `log`)
- Connecting local repo to GitHub (`remote`, `push`, `pull`)
- Branching and merging
- Writing clear commit messages
- Following a simple team-style workflow (branch → commit → push → merge)
